Proyecto assistant, es un programa que finge ser un sistema inteligente de la computadora, programado en powershell, y que permite acceder a archivos, y principalmente, dar información sobre el estado del sistema, el programa cuenta con 8 comandos:  
- status: devuelve información sobre el estado del sistem  
- time: devuelve la fecha   
- saved: lista los contenidos de la carpeta y permite leer los contenidos de un archivo  
- save: permite editar o crear archivos de texto  
- delete: permite eliminar archivos  
- run: permite ejecutar archivos  
- help: lista los comandos disponibles  
- 6: cierra el programa
